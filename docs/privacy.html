StoryRelay privacy policy

Effective 18 October 2026.

StoryRelay has no developer-operated analytics or collection endpoint. It stores your selected world URL and transient tool messages, the last request key and recovery data in extension-local browser storage. Data is not synced by StoryRelay. Disconnecting clears this local relay data.

During a turn you explicitly start, the extension reads the latest final assistant messages and sends requested tools to your selected world. It inserts real tool results, including story context and save data, into the same DeepSeek conversation. DeepSeek and your world operator process these data under their own policies. Do not connect a world whose data you are not authorized to share with DeepSeek.

World sign-in cookies are used by normal same-origin browser requests. StoryRelay does not read cookies, login tokens or passwords, does not call DeepSeek's private APIs and does not send authentication credentials to the model.

Only DeepSeek and the single world origin you explicitly grant are accessed. No shell, file-system, native messaging or arbitrary URL-fetch tool is exposed. All extension code is bundled locally. Uncertain submissions remain unconfirmed until the server returns a real receipt.

Disconnect stops new work; it cannot reverse an already submitted server transaction. StoryRelay does not delete your DeepSeek conversations or cloud game saves. Remove those through their respective services.

Support and privacy questions: use the project's GitHub Issues. Never post credentials, private world text or saves in a public issue.
