# Contributing

Run `npm test`, `npm run build`, and `npm run check:release`. Browser tests use a disposable Chromium profile with synthetic world/model replies. Include failing regression evidence for adapter changes. Keep `extension/content.js` generated from `src/`.

Do not add proprietary novels, production saves, private origins, tokens, browser profiles or remote executable code. New adapters must document their authentication, branch/action binding, idempotency and recovery semantics. Add concrete evidence before making compatibility or novelty claims.
